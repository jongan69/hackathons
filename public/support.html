Support

Last updated August 9, 2026

Support is handled in the public GitHub repository. Never post passwords, API keys, private application materials, or other sensitive information in an issue.

Incorrect or missing listing

Open a GitHub issue with the event name, official organizer URL, and the field that needs correction. Verify urgent deadline questions with the organizer directly.

Site bug or accessibility problem

Report the page, browser or device, what you expected, and what happened. A screenshot is useful when it does not contain personal information.

Sponsorship interest

Use the sponsorship-interest form. Submitting a request does not guarantee placement.
